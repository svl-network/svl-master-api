### ✨ What is the Sunveil Network?

Sunveil eliminates the traditional headaches of Minecraft multiplayer hosting, port-forwarding, and modpack management. Whether you're a server owner or a player, everything just works seamlessly.

---

### 🌟 Key Highlights & Features

#### 🛡️ 1. Zero-Portforwarding Encrypted Relay
* Host Minecraft servers directly from your home network, LAN, or VPS **without exposing your home IP or touching router port-forwarding**.
* Unlimited realms support powered by central SNI dynamic hostname routing (`realm_xyz.sunveil.net`).

#### ⚡ 2. Automatic Mod Delta & Anti-Cheat Sync
* Players never need to manually download zip files or search for matching mod versions again.
* **SVL Connect** automatically synchronizes required server mods, configs, and resource packs via high-speed Modrinth edge CDNs with SHA-256 integrity verification.

#### 🪟 3. Sunveil Connect (Desktop Launcher)
* Native, high-performance desktop launcher built with C++ and Qt.
* Real-time hardware perimeter security, one-click server joining (`sunveil://connect`), and automatic mod cache management.

#### 🌐 4. Custom & Standalone Server Support
* Want to list a server that isn't using the bridge plugin? You can now manually register any standalone, vanilla, or network server directly via the web dashboard!

#### 📊 5. Real-Time Web Portal & Fleet Management
* Manage up to **4 server slots** per account on [`dash.sunveil.net`](https://dash.sunveil.net).
* Live telemetry: CPU, RAM, TPS, player lists, instant daily server boosts, and custom banner branding.

### 🛠️ Quick Setup for Server Owners in 60 Seconds:
```text
1. Register your free account on https://dash.sunveil.net
2. Copy your License Key from your dashboard
3. Drop svl-bridge-<loader>.jar into your server's plugins/mods folder
4. Paste your key into plugins/SunveilBridge/config.yml (or set SVL_LICENSE_KEY)
5. Start your server — Your encrypted realm tunnel is immediately live!
```
