Architecture

How synchronization works

A deterministic three-step process between server bridge, master API registry, and player client.

01

Server bridge inspection

Install svl-bridge on your Minecraft server. The bridge hashes all server mods, config assets, and loader requirements into a deterministic SHA-512 manifest.

02

Relay & registry registration

The bridge connects via WebSocket tunnel to the Master API, allocating an encrypted zero-portforwarding subdomain (e.g. myrealm.realms.sunveil.net).

03

Delta client sync & launch

Sunveil Connect compares the player's local directory against the manifest, downloads only missing or changed files from Modrinth edge CDNs, verifies hashes, and launches.

Features

Engineered for server reliability

Production-grade features for server administrators and community players.

Automated delta synchronization

Players never download redundant files. Only modified or missing configuration files and mods are transferred over encrypted streams.

Zero-portforwarding tunnels

Host servers behind CGNAT, home routers, or residential connections with high-performance raw TCP multiplexed relays.

Modrinth edge CDN routing

Direct integration with Modrinth infrastructure delivers client optimization mods (Sodium, Iris, Lithium) with high-speed CDN delivery.

SHA-512 integrity verification

Every binary and jar file is verified against cryptographic hashes before execution, preventing corrupted or tampered downloads.

Real-time performance telemetry

Monitor server tick rate (TPS), memory allocation, CPU load, and connected player counts directly from your owner dashboard.

Multi-account & offline support

Native support for official Microsoft OAuth2 profiles alongside local offline profiles for development and testing environments.

Onboarding

Connect your server in minutes

Step-by-step setup to register your Minecraft realm on the Sunveil network.

Create account

STEP 02
Generate license

Obtain your unique bridge license key (e.g. SVL-FREE-xxxx-xxxx).

STEP 03
Install bridge jar

Place the bridge JAR for your server engine into your plugins or mods directory.

Configure YAML
