How synchronization works

A straightforward technical process between server, API registry, and player client.

1

Server bridge

Install the svl-bridge plugin on your Minecraft server. The bridge inspects local mod files and generates a manifest with version metadata and SHA-256 hashes.

2

Synchronization registry

The bridge communicates with the Sunveil Master API to publish current server requirements, active player counts, and Modrinth CDN mirrors.

3

Client update

Sunveil Connect compares the player's local installation against the server manifest, downloads only missing or changed files, verifies checksums, and launches the game.

Core capabilities

Functional features provided by Sunveil Connect and the server bridge.

Client synchronization

Synchronize required mods, configuration files, and asset versions between the server and player installations automatically.

Incremental downloads

Only transfer files that have changed or are missing instead of repeatedly downloading complete archives.

Modrinth integration

Use Modrinth metadata and CDN downloads to install client-side optimization mods such as Sodium, Iris, and performance utilities.

File integrity verification

Verify downloaded files against server-provided SHA-256 and SHA-512 hashes before allowing the client to execute them.

Server discovery

Players can browse registered servers in the desktop client's multiplayer browser and connect with one click.

Account handling

Support for official Microsoft OAuth2 authentication alongside local offline profiles for flexible local testing.

Technical specifications

System requirements, protocols, and compatibility details.

Desktop Client

  • Platform Windows 10 / 11 (64-bit)
  • Framework C++ / Qt 6
  • Runtime Java 17 / 21 (bundled/detected)
  • Authentication Microsoft OAuth2 & Offline
  • Distribution Portable & Installer EXE

Server Bridge

  • Environment Java 17 or higher
  • Server Software Paper, Spigot, Fabric, Forge
  • Minecraft Versions 1.20.x, 1.21.x
  • Configuration YAML (config.yml)
  • Plugin Format Standard Java JAR

Protocol & Security

  • API Transport HTTPS / TLS 1.3
  • Payload Format JSON REST API
  • Hash Algorithm SHA-256 & SHA-512
  • Session Auth HMAC SHA-256 JWT
  • CDN Mirroring Modrinth Edge Network

Server owner onboarding

How to connect your Minecraft server to the Sunveil network.

Step 1
Create account

Register a developer account in the dashboard using your email address.

Step 2
Generate key

Obtain your unique bridge license key (e.g. SVL-FREE-xxxx-xxxx).

Step 3
Install plugin / mod

Download the bridge jar for your engine (Fabric, Forge, NeoForge, Paper) and drop it into your plugins or mods folder.

Step 4
Configure YAML

Paste your license key into plugins/SVLBridge/config.yml under master-api.license-key.

Step 5
Ready to join

Start your server. Players can now synchronize and connect from Sunveil Connect.
