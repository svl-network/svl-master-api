Acceptable Use Policy

Last updated: August 18, 2026 | Safety, file integrity, and network protection guidelines

1. Purpose and Application

This Acceptable Use Policy ("AUP") outlines the security standards and usage rules for all users, developers, and server administrators connecting to the Sunveil network, the Master API, or utilizing Sunveil Connect and the svl-bridge plugin.

2. Prohibited Content and Malicious Payloads

You may not distribute, host, mirror, or link to any file or package through the Sunveil synchronization infrastructure that contains or executes:

  • Malicious Code: Viruses, worms, trojans, ransomware, keyloggers, botnets, or spyware.
  • Credential Harvesters: Payloads designed to extract Minecraft session tokens, Microsoft OAuth tokens, browser credentials, or local passwords.
  • Unauthorized Executables: Native binaries (.exe, .dll, .so) disguised as Minecraft Java archives (.jar) without appropriate security declaration and player disclosure.
  • Exploits and Droppers: Code designed to exploit Java Virtual Machine (JVM) vulnerabilities or execute unauthorized background commands on player machines.

3. Network and API Integrity

Users and administrators must not compromise the availability, performance, or integrity of Sunveil network infrastructure:

  • Denial of Service: Flooding Master API endpoints, heartbeat listeners, or download proxies with automated requests.
  • Authentication Bypass: Forging client signatures, spoofing Hardware IDs (HWID), or circumventing rate-limiting rules.
  • Unsolicited Scraping: Mass scraping of registered server listings or user databases using unauthorized bots.
  • License Abuse: Sharing or publicly distributing private bridge license keys intended for single server deployments.

4. Sunveil Secure Tunnel Policy & Anti-Botting

The Sunveil Secure Relay and Outbound Tunnel service is dedicated exclusively to Minecraft game server connectivity. Using the tunnel for any other service, protocol, or illegal activity is strictly prohibited:

  • Sole Minecraft Purpose: Only authentic Minecraft Java Edition protocol handshakes are accepted. Non-Minecraft traffic (HTTP/S, SSH, Telnet, SOCKS, C2 payloads, cryptomining, P2P/BitTorrent) is blocked automatically at the edge.
  • Anti-Botting & Flooding: Automated botting, spamming, artificial player flooding, connection storming, and stress-testing of servers or relay endpoints are forbidden and mitigated via real-time rate limiting and IP blocking.
  • Illegal Activities: Operating phishing sites, distributing illegal media, hosting malicious command-and-control servers, or engaging in cyber attacks through Sunveil Tunnels will lead to immediate permanent ban and law enforcement escalation.

5. Content Rights and Intellectual Property

Server administrators must respect intellectual property rights. You may not distribute mod packages, shader assets, or resource packs through server manifests if the respective authors explicitly prohibit distribution or mirroring, unless you have obtained written authorization.

6. Enforcement and Account Suspension

Sunveil reserves the right to immediately invalidate bridge license keys, hide server listings from the Sunveil Connect browser, and suspend developer accounts found to be in violation of this Policy. Severe security violations involving malicious file distribution will be reported to appropriate law enforcement authorities.
